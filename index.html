Wer ich bin

Über mich

Seit 35 Jahren bin ich als Softwareentwickler im Automotive-Bereich tätig – von Embedded-C und LabWindows/CVI über klassische Windows-Anwendungen bis hin zu C, C++ und C#. In dieser Zeit habe ich zahlreiche Mess-, Prüf- und Steuerungssysteme mitentwickelt.

Seit einiger Zeit hat mich die Begeisterung für Künstliche Intelligenz gepackt: Workflow-Automatisierung mit n8n und „Vibe Coding" mit Tools wie Claude Code eröffnen mir völlig neue Möglichkeiten, Ideen schnell in funktionierende Software zu verwandeln.

Aktuell befinde ich mich auf der Suche nach neuen beruflichen Herausforderungen in diesem Umfeld – ob als Entwickler, Automatisierungs-Experte oder in einer Rolle, die klassische Software-Erfahrung mit modernen KI-Werkzeugen verbindet.

Softwareprojekte

n8n · Buchhaltung

Buchhaltungs-Automatisierung

  • Erfasst eingehende Rechnungen automatisch aus E-Mails
  • Legt Belege quartalsweise für die Umsatzsteuer-Voranmeldung ab
  • Trägt die Werte je Quartal in ein Excel-Sheet ein, das anschließend händisch in Elster übertragen wird
Next Step: Automatischer Übertrag der Werte direkt nach Elster.
gebaut mit n8n & Claude Code
n8n · WhatsApp

WhatsApp-Blitzer-Workflow (lokal)

  • Durchsucht Webseiten lokaler Radiosender nach aktuellen Blitzermeldungen
  • Filtert die Meldungen nach einem definierten Umkreis
  • Leitet passende Treffer automatisch in eine WhatsApp-Gruppe weiter
gebaut mit n8n & Claude Code
n8n · WhatsApp

WhatsApp-Blitzer-Workflow (überregional)

  • Bezieht Blitzermeldungen aus einer überregionalen WhatsApp-Gruppe
  • Filtert die Meldungen nach einem definierten Umkreis
  • Postet die relevanten Meldungen automatisch in die eigene WhatsApp-Gruppe
gebaut mit n8n & Claude Code
n8n · Real Estate

RE-Auto-Reply-Agent

  • Liest Kunden-E-Mails mit Anfragen zum Immobilienportfolio eines Maklers oder Vermieters
  • Beantwortet Info-Anfragen automatisch mit den passenden Objektdaten
  • Verschickt bei Besichtigungswünschen einen Cal.com-Link zur Terminauswahl
  • Ermöglicht Terminabsage oder -verschiebung im Kalender und versendet je nach Zweig die passende Antwortmail
Next Step: Abfrage von Bonitätsdokumenten bei Besichtigungswunsch sowie Integration eines Telefon-Voice-Systems.
gebaut mit n8n & Claude Code
Web-App · OCR

Benzinverbrauch-Tracker

  • Foto von Zapfsäule sowie Tacho/Trip-Zähler aufnehmen oder hochladen – Literzahl, Preis und gefahrene Kilometer werden per OCR ausgelesen
  • Erkannte Werte lassen sich prüfen und korrigieren, der Durchschnittsverbrauch wird live berechnet
  • Speichert jeden Tankvorgang in einer SQLite-Datenbank, bisherige Einträge sind tabellarisch einsehbar und löschbar
HTML5, Node.js/Express, SQLite, Tesseract-OCR · gebaut mit Claude Code
